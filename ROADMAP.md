# Roadmap

Where the AutoDrive FS25 Editor is heading. This is a rough outlook, not a promise: plans change, and there are no dates. What is already done is in the [CHANGELOG](CHANGELOG.md).

The editor supports only Farming Simulator 25.

- **Generators.** The editor builds the hard parts of a network the way experienced course authors do: junctions, lanes at stations connected to the roads, the way into sheds. The manual tools are for fixing the rest.
- **Route finder.** Faster, closer to hand-made courses, and a clear message where no drivable route exists.
- **More from the game.** Building outlines on the map, and checks done by the running game through the companion mod, such as planned roads that hit obstacles or markers AutoDrive cannot reach.
- **Easier editing and more checks.** Quicker ways to find, select and inspect nodes, and checks for problems AutoDrive runs into while driving, such as markers that cannot be reached.
- **Speed and safety.** Faster loading of large maps, and a warning when the game changed a file while it was open in the editor.
