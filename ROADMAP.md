# Roadmap

Where the AutoDrive FS25 Editor is heading. This is a rough outlook, not a promise: plans change, and there are no dates. What is already done is in the [CHANGELOG](CHANGELOG.md).

The editor supports only Farming Simulator 25.

- **Driving checks.** Find problems AutoDrive runs into while driving: markers that cannot be reached, dead ends, turns too tight for the vehicle, markers with the same name.
- **Field rings.** A generator for the one-way rings along the field edges, with a gate and markers.
- **Editable generated pieces.** Change a generated junction or yard road by its handles afterwards, instead of undoing it and generating it again.
